The docs deploy publishes them live, with their transitions, speaker notes and presenter view (<SlidesLink>all decks</SlidesLink>), and as PDFs, below and on the [slide decks release](https://github.com/Iconem/terrain-viewer/releases/tag/slides-2026-10-05). Light docs: ideas, bullets, screenshots, the numbers.

## Presenting

Open a deck, then **F** for full screen and **P** for the presenter window: the current slide, the next one, the speaker notes, a timer and a page jump, kept in step with the audience window (both in the same browser). Arrows, Space or Page Down move on; **O** shows every page, **B** and **W** blank the screen, **L** is a laser pointer, **?** lists the keys. The PDF, PowerPoint and HTML exports are in the deck's toolbar too.

The online decks are read-only: the inspector, its comments and the inline text edits write back to the slide sources, so they only run with `pnpm slides` on a checkout.

## All the PDFs

Each opens in place; a deck is 12 to 23 MB.

## Working on them

From the repository root:

```bash
pnpm slides:install   # once: the workspace has its own install
pnpm slides           # dev server with the inspector, http://localhost:3200
pnpm slides:static    # the static site as it will be online, http://localhost:4180/docs/slides/
pnpm slides:pdf       # the static site and the five PDFs, in .cache/slides-site/
pnpm dev:all          # app, docs and slides together
```

The decks' screenshots are the docs site's own (`docs/public/screenshots`), copied in before a build, so the repository holds each picture once; the built site and the PDFs are never committed.
