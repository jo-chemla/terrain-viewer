The app ships a guided tour (Coachmark) that auto-starts on first visit, or any time from Settings → **Take the Tour**. It's five shared intro steps, then a fork — go deeper on Terrain visualization tools, or jump into Historical Imagery. This page walks through every step of both branches as a screenshot gallery; the in-app tour itself is generally the faster way to get oriented — <a href="https://terrain-viewer.iconem.com/?startTour=true&lat=45.9763&lng=7.6586&zoom=12.6&pitch=60&bearing=-20&viewMode=3d&showHillshade=true&exaggeration=1" target="_blank" rel="noopener noreferrer">open the app with the tour running ↗</a> (or click any thumbnail below to zoom in, then arrow-key through the rest).
