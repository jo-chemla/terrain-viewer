The app ships a guided tour (Coachmark) that auto-starts on first visit, or any time from Settings → **Take the Tour**. It's five shared intro steps, then a fork — go deeper on Terrain visualization tools, or jump into Historical Imagery. This page walks through every step of both branches; the in-app tour itself is generally the faster way to get oriented, but the screenshots below are handy as a reference or before you've even opened the app.
