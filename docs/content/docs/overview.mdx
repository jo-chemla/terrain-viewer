Terrain Viewer is a browser-based terrain and historical-imagery visualization tool built on [MapLibre GL](https://maplibre.org/maplibre-gl-js/docs/) via [react-map-gl](https://visgl.github.io/react-map-gl/). Every setting lives in the URL query string, so any view is shareable as a plain link.

## Sidebar groups

- **General Settings** — View Mode (2D/3D/Globe), Split Mode (Off/Overlay/Side, up to an 8-view grid), Project import/export
- **Visualization Modes** — see [Terrain Visualization Modes](/features/visualization-modes)
- **Bookmarks** — see [Bookmarks](/features/bookmarks)
- **Sources** — Terrain and Basemap, including the combined Historical Imagery entry — see [Basemaps & Historical Imagery](/features/basemaps-and-historical)
- **Options / Tools** — per-mode option panels, Drawing, Elevation Picker, Animation, Source Info
