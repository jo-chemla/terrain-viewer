Five decks, written as React pages with [open-slide](https://open-slide.dev) in the repository's `slides/` workspace and exported to PDF by the docs deploy. Light docs: ideas, bullets, screenshots, the numbers.

| Deck | What it covers | PDF |
| --- | --- | --- |
| **Terrain Viewer** | What it is, the sources, the visualization modes, split and compare, export | [terrain-viewer.pdf](/docs/slides/terrain-viewer.pdf) |
| **Historical imagery** | The timeline, the providers, the catalogs (open data after a disaster, national archives, old maps), coverage | [historical.pdf](/docs/slides/historical.pdf) |
| **Tools** | Elevation picker and profiles, plane slicer, drawing, georeferencer, sun shadows, iso-lines, bookmarks | [tools.pdf](/docs/slides/tools.pdf) |
| **Research themes** | Landscape archaeology and earth processes: what the modes show and the papers behind them | [research.pdf](/docs/slides/research.pdf) |
| **Under the hood** | The equations, the client-side tile protocols, the registry, what runs where | [under-the-hood.pdf](/docs/slides/under-the-hood.pdf) |

To present them live, with their transitions and speaker notes:

```bash
cd slides
pnpm install --ignore-workspace
pnpm dev          # http://localhost:5173/s/terrain-viewer, /s/historical, /s/tools, /s/research, /s/under-the-hood
pnpm pdf          # the PDFs, from a running dev or preview server (CHROME_PATH to a Chromium)
```

The decks' screenshots are the docs site's own (`docs/public/screenshots`), copied in before a build, so the repository holds each picture once.
