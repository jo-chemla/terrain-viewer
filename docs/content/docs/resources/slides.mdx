Five decks, written as React pages with [open-slide](https://open-slide.dev) in the repository's `slides/` workspace, published by the docs deploy both live (with their transitions and speaker notes, [all decks](../../slides/)) and as PDFs, also attached to the [slide decks release](https://github.com/Iconem/terrain-viewer/releases/tag/slides-2026-10-05). Light docs: ideas, bullets, screenshots, the numbers.

| Deck | What it covers | Live | PDF |
| --- | --- | --- | --- |
| **Terrain Viewer** | What it is, the sources, the visualization modes, split and compare, export | [present](../../slides/s/terrain-viewer/) | [terrain-viewer.pdf](../../slides/pdf/terrain-viewer.pdf) |
| **Historical imagery** | The timeline, the providers, the catalogs (open data after a disaster, national archives, old maps), coverage | [present](../../slides/s/historical/) | [historical.pdf](../../slides/pdf/historical.pdf) |
| **Tools** | Elevation picker and profiles, plane slicer, drawing, georeferencer, sun shadows, iso-lines, bookmarks | [present](../../slides/s/tools/) | [tools.pdf](../../slides/pdf/tools.pdf) |
| **Research themes** | Landscape archaeology and earth processes: what the modes show and the papers behind them | [present](../../slides/s/research/) | [research.pdf](../../slides/pdf/research.pdf) |
| **Under the hood** | The equations, the client-side tile protocols, the registry, what runs where | [present](../../slides/s/under-the-hood/) | [under-the-hood.pdf](../../slides/pdf/under-the-hood.pdf) |

To work on them locally:

```bash
cd slides
pnpm install --ignore-workspace
pnpm dev          # http://localhost:5173/s/terrain-viewer, /s/historical, /s/tools, /s/research, /s/under-the-hood
pnpm pdf          # the PDFs, from a running dev or preview server (CHROME_PATH to a Chromium)
```

The decks' screenshots are the docs site's own (`docs/public/screenshots`), copied in before a build, so the repository holds each picture once.
