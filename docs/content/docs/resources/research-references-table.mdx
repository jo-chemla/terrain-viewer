The same references as [Research References](/resources/research-references), as a table. Click a column to sort, click **Grouped** to go back to sections and groups, and click a section or group row to fold it. **Has** filters cycle through any, yes and no. The search, sort, filters and columns are kept in the address bar, so a filtered table can be shared as a link. **Export CSV** saves the rows shown.
