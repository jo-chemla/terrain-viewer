Terrain Viewer's modes follow published methods: the relief visualizations of archaeological LiDAR, the classic terrain derivatives of geomorphometry, and the global elevation models most studies start from. This page gathers the papers behind them. Where a study has a clear area, a link opens the app there with the modes it used, on the same data when the app has it, so the method can be seen on real terrain in the browser.

Every reference below was checked against its DOI or publisher page. To suggest one, open an issue on [GitHub](https://github.com/Iconem/terrain-viewer/issues).

## Relief visualization

Sky-view factor, openness, local relief model and their blends: the toolbox of archaeological LiDAR interpretation, most of it collected in RVT. In the app: [Relief Visualization](/features/visualization-modes).

## Using this with an assistant

Each "Open in Terrain Viewer" link is an ordinary URL. An assistant can build the same for any place with the [Terrain Viewer skill or llms.txt](/features/ai-assistants): "show me the sky-view factor over the area of this paper".
