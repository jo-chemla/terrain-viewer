Terrain Viewer is a client-side app, React and MapLibre GL, with no backend: every visualization is computed in the browser from the elevation tiles, and every setting lives in the URL. These pages are for anyone running it locally, embedding it, or reading its source.

- [Setup](/dev/setup): running the app, the URL as app state, the structure of the repository and its architecture. Start here.
- [Tech stack](/dev/tech-stack) and the [equations](/dev/equations) behind the visualization modes.
- [The URL as an API](/dev/url-api) and the generated [state reference](/dev/state): every query parameter and local setting.
- [Custom protocols](/dev/custom-protocols): the `slope://`, `svf://`, `lerc://` and other tile handlers, the [terrain analysis pipeline](/dev/terrain-analysis-pipeline) and the [tile caches](/dev/tile-caches).
- Historical imagery: [Esri Wayback](/dev/esri-wayback) and [Google Earth historical](/dev/ge-historical).
- Map and interface internals: [camera sync](/dev/camera-sync), [map bounds](/dev/map-bounds-and-underzoom), [layer order](/dev/layer-order), [draping](/dev/draping), the [product tour](/dev/product-tour), [coverage footprints](/dev/coverage-footprints) and the [demo videos](/dev/demo-videos).
- [Advocacy](/dev/advocacy), the [upstream requests](/dev/upstream-requests) and [indexing and SEO](/dev/indexing-and-seo).
