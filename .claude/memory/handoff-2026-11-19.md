## What was added (21635b4 to ad9baac)

**Feature Iterator** (`components/TerrainControlPanel/TerraDrawSystem.tsx`, in `TerraDrawLayers`)
- `scrollTo=featureIterator` in a link opens Drawing and starts the
  iterator on the first `drawingUrl` layer with features. With no layer it
  only opens Drawing. A link that starts it does not fit the whole layer
  first (that fit used to win the race and leave zoom 1.6).
- Order: file order or a numeric property, with a direction button.
  `iteratorSort=quality` is highest first, `iteratorSort=quality:asc` lowest.
- Filter: one value of a text property with 2 to 40 distinct values, with
  counts. `iteratorFilter=property:value`. It narrows what is walked, not
  what is drawn.
- `iteratorSort` and `iteratorFilter` are read from `window.location` once,
  NOT nuqs state: they are not in `QUERY_STATE_PARSERS`, not in the
  generated URL reference, and a bookmark restore in place cannot set them
  (hence the `reload: true` preset, below).
- The current feature is ringed in amber on every view:
  `IteratorHighlightLayer` in `components/LayersAndSources/IteratorHighlightLayer.tsx`,
  fed by `iteratorHighlightAtom`. It follows the Drawings show checkbox and
  opacity slider and hides with its layer. Tested on points, lines, polygons.
- Panel is one grid (Feature, Filter, Order, Zoom), controls 28 px high.

**Drawings**
- CSV of points imports (file, URL, `drawingUrl`): `csvToPoints` in
  `lib/remote-vector.ts`; lat/latitude/y and lon/lng/long/longitude/x.
- `drawingUrl` is a comma-separated list, one layer per URL.
- A linked layer is remembered: once per page load the URLs of stored
  `sourceUrl` layers go back into `drawingUrlsAtom` (so into the address
  bar) and are fetched again. Deleting the layer forgets it.
- A loading linked layer shows a spinner and "Loading" until its features
  are drawn (`drawingUrlsLoadingAtom`); a placeholder row when no row exists.
- The empty default "Layer 1" is not listed beside a linked layer (hidden,
  not deleted).

**Hypsometric tint** (`hypsometric-tint-options-section.tsx`)
- Range button with three states: off, set once, follow the view
  (`hypsoAutoRange`, 1st to 99th percentile of the in-view DEM, re-read on
  map idle, changes under 2% skipped).
- Ramp tab is URL state: `colorRampTab`, written in the same `setState` as
  `colorRamp`. The old `colorRampTypeAtom` is gone. 31 ramp names are in
  two tabs (always Top Qgs plus Topo, TopoBath or Temp), same id. A link
  with no tab opens on the first tab that holds the ramp. Jonathan
  confirmed the long-standing "tab jumps back to Top Qgs" bug is fixed.
  Eight shared ramps are hidden by the default licence filter
  (`open-distribute`), so switching tab replaces them with the tab's first.

**Fixes worth knowing**
- `components/LayersAndSources/MapSources.tsx`: the probed max zoom was
  reset on every move past 0.1 degree, which put the declared maxzoom back
  in the `<Source key>` and remounted terrainSource and hillshadeSource
  twice per move (white flash). Now reset only when the source changes.
- Split pills read "A: Hillshade" (was "AHillshade") when only modes are named.
- LRM point and path read at the view's zoom; mosaic rows are looked up in
  Web Mercator (`mercatorRowFraction` in `lib/elevation-query.ts`).
- Iso-line smoothing slider (`isolineSmooth`).
- The two worker switches are gone from Settings; both are always on. The
  old main-thread contour paths are still in the code, unreachable, kept
  until Jonathan says to remove them.

**Other**
