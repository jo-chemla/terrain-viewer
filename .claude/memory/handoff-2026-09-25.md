## Testing: how not to lose an hour

The agent preview browser does not fire rAF. Use Playwright under `.cache/pw/` (gitignored): `node <script>.mjs` against the dev server on 5204 (`DEVTOOLS_EVENT_BUS_PORT=42171 DOCS_PORT=3101 pnpm app --port 5204`).

- **Hard-cap every script** (`setTimeout(() => process.exit(1), 120000)`) and run independent ones in parallel. A stalled probe with no cap cost ~25 min this sprint.
- **Instrument before rerunning**: poll progress and `__tileResultCacheStats()` every 10 s instead of waiting for a result.
- **Never `import("/lib/...")` from a probe to call app code**: Vite may serve a different module copy (empty toast store, formerly empty registry). Use the dev hooks: `window.__tv = { mapRefs, state, setState }`, `window.__draw` (Terra Draw), `window.__tileResultCacheStats()`.
- `page.route` filters must exclude localhost, or they also block app modules whose paths contain the pattern.
- Useful scripts: `exportprobe.mjs` (GeoTIFF export per source), `contourprobe.mjs`, `pitsprobe.mjs`, `hoverprobe.mjs`, `undocam.mjs`, `stallshot2.mjs` (toast + refire after pan, screenshot), `gotoprobe.mjs`.
- Docs dev server needs `pnpm install` inside `docs/` in a fresh worktree (done here), then `cd docs && pnpm exec next dev -p 3101`.
