## Shipped this sprint

- **`vrt://` protocol** — GDAL VRT mosaics read in the browser
  (`lib/vrt-protocol.ts`, docs `/dev/vrt-protocol`); per-source "always via
  titiler" pin; 2 levels of overzoom for every source; a "zoom in to zN"
  toast when the camera is below a source's floor (VRT-derived or declared
  minzoom) — `MapSources.tsx`, primary view only.
- **Coverage overlays, one switch "3D and LiDAR coverage"**: Google 3D
  (see [[google-3d-coverage-dead-end]] — the delta-rule bug), Bing 3D
  (subtree bitstream), Esri Integrated Mesh (see [[esri-3d-coverage]] —
  typeKeywords, ≥5 km², anonymous `?f=json` check, Scene Viewer `?url=`
  links with a backed-off camera), FLAI (COPC octree). All built by hand
  under `docs/scripts/`, outputs committed in `public/coverage/`; the
  deploy workflow builds none of them. Fetched with `cache: "no-cache"`.
- **Data layers picker** (`data-layers-modal.tsx`): cards with cropped
  thumbnails (`docs/scripts/build-screenshot-thumbs.mjs`, ffmpeg, 30 % crop
  around 0.44/0.5), Tools row that reveals sidebar sections
  (`revealSectionAtom` now opens the right macro group), group titles that
  open their section, scroll fade. Trigger in the panel title bar AND next
  to the Visualization Modes pin, whose fold/expand/pin is one three-state
  control (`SectionFoldPinToggle`).
- **Section header shortcuts**: Home → General Settings, Gallery →
  Bookmarks (modal hoisted outside the Section or it is unmounted when
  folded), Snapshot → Download and Snapshot (labelled button kept).
- **Card screenshots** re-captured over the Matterhorn with the docs'
  own parameters (`docs/scripts/capture-viz-mode-cards.mjs`, throwaway
  Playwright): hillshade, hypso, basemap, aspect — all plan view
  (`lat=45.9763&lng=7.6586&zoom=12.6&pitch=0&bearing=0&viewMode=3d`).
- **Wayback**: the Open-In link needs no release id; the tilemap walk runs
  only when some view is on a historical basemap AND its ESRI pill is on.
- **Esri camera** for Scene Viewer links: camera backed off the target
  (`esriCamera` in `CoverageOverlayLayer.tsx`), diagonal fov 55°, z above
  sea level, and `2^(zoom+1)` because maplibre zooms are on 512 px tiles.
- nDSM rows and the difference dialog offer "load from library" for
  missing operands; drawing layers show `[n]` counts with a Base UI

## Deferred / open

- Open Buildings 2.5D: storage.googleapis.com still sends no CORS header
  (re-checked 2026-09-24), so the two BRA sample VRTs stay titiler-pinned.
  A single VRT per year is not a few-MB file: ~147 manifests x ~2 600 tiles
  = ~380 000 sources, ~130 MB flat. It would need nested per-zone warped
  sub-VRTs, which `vrt://` does not read. Jonathan may test the sample
  entries natively with a CORS browser extension (flip the per-source
  "Always via titiler" switch).
- Idea for later: port `vrt://` to also read a GeoParquet/GeoArrow tile
  index (PDAL's `tindex` shape, probably via loaders.gl), see
  https://pdal.org/en/2.9.3/tutorial/tindex/index.html.
- Remaining card re-captures (contours, slope, curvature, TPI, LRM, matcap,
  phong, shadows) if a uniform set is wanted; SVF/Openness hang headless.
- Coverage rebuilds: all four are manual. A monthly cron workflow that runs
  the four scripts and opens a PR (or publishes to a release) is the plan;
  Google's shipped pipeline mints its layer id from `VITE_GOOGLE_API_KEY`
  at run time, so that secret is all it needs. The captured Earth
  `ml:xsr:c:` token route is dismissed, not just deferred.
- Push authorisation is per message; `main` deploys both remotes.

## Gotchas that bit this sprint

- **Bash heredocs mangle backslashes** (`\\u00b7` → `·` → the real
  character): write patch scripts with the Write tool, run with python.
- **`grep -c` exits 1 on zero matches** and kills an `&&` chain — the
  docs typecheck "failed" once with zero errors.
- **Vite watches everything but node_modules/.git**: 116 000 files under
  `.cache/` wedged the dev server (1.6 GB, CLOSE_WAIT). `server.watch.
  ignored` now covers `.cache`, `dist`, `docs/out`, `docs/.next`.
- The dev server on 5204 was restarted by an agent from this worktree with
  `DEVTOOLS_EVENT_BUS_PORT=42171` (42170 was taken); right after the first
  page load Vite pre-bundles for up to a minute and requests queue.
- **Piping a dev server through `head`** kills it on SIGPIPE.
- **`next build` typechecks `docs/scripts`**: a dynamic import of a
  non-dependency broke the deploy once.
- The hypso card needs the docs' exact ramp params (`colorRamp=tv-a`,
  `minElevation=1450`, `maxElevation=8620`, slider bounds); invented
  ranges come out single-hued.
- Playwright: fresh `chromium.launch()` per shot; `matcapRenderer=raster`.
- Per-zoom measurements landing on a round fraction mean "test the
  decoder against itself", not "theorise about the data".
