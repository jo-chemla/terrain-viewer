- **Desktop**: after the next update, the update notice should say "about
  37 MB" then the exact size; pictures in the changelog and the picker
  should show. The take scripts now swap the cursor to the Windows hand
  over links and buttons (video/takes/basic-modes-v6, cursor-hover.b64):
  not yet seen in a recorded take. launcher.exe takes a query string or a
  full link on its command line (a964418): not yet tried on an installed
  build.
- **Local COG, second run (Web Mercator files, 2026-10-10,
  .cache/desktop-test/run2/)**: the Bhote Koshi 0.5 m DSMs and 2 m dh
  COGs (Downloads/bhotekoshi-3857) all DRAW once "Fit to its extent" is
  clicked (relief within a second), so the reader is fine with 3857 COGs.
  Two bugs seen: (1) nothing flew to a freshly added file (one flight
  went 60 km off at z20, probably the fence; the others did not move), so
  the map stayed blank until the pin: fixed the same day, a forced fit
  runs once when the custom terrain list grows (terrain-source-section).
  (2) **No-data is not masked for local COGs**: the DSMs' NoData (-1e6,
  in the GDAL tag) reaches the terrain, so the hillshade draws black
  outlines along every hole and the tilted 3D shows walls dropping at
  the hole edges. The opt-in nodata floor/fill controls exist (Advanced
  in the modal, lib/nodata.ts) but nothing prefills them from the file's
  tag, and a fill value still leaves a step. The right fix is a mask
  (alpha) for the reader's no-data pixels, as the WMS path does
  ([[wms-nodata-two-paths]]); a cheap first step is prefilling the floor
  from the GDAL_NODATA tag read in validateLocalCogFile. Also seen: faint
  tile-seam lines and a dark frame around the extent; the Syabrubesi DSM
  was listed twice after the first add (a double add?).
- **Zenodo Chamoli COGs** (library entries): no CORS header, so they cannot

## How to test without wasting an hour

- Headless checks of the app: Playwright from `.cache/pw` (`channel:
  "chrome"`); the timeline needs
  `?basemapSourceA=historical&historicalActiveSourceA=wayback&viewMode=2d`.
- Dev server of the worktree on 5204 (`pnpm exec vite --port 5204`); after
  a dependency bump restart with `--force` or trust the version-split toast.
- Recording a take: copy the latest `video/takes/*` scripts; production
  site; one rehearsal; the lessons list in the memory note.
- The installed light app over CDP: `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9333`
  on `launcher.exe`, then `chromium.connectOverCDP`.
