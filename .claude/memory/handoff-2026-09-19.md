## Gotchas learned

- Bash heredocs mangle `\b`, `\(` and CRLF in patch scripts: write Python patch scripts with the Write tool, normalise CRLF, and check bytes when a regex is involved (a `\b` once became a backspace character in a committed file).
- MapLibre's DEM decoder ignores alpha and the browser premultiplies it: a transparent DEM pixel decodes to -10000 m. Alpha 254 with the fill value in RGB is the way to flag holes without pits.
- titiler: `resampling` is the read kernel, `reproject` the warp kernel (default nearest); pass the file's nodata or float sentinels crash `terrainrgb`; 404 outside the footprint is normal and MapLibre keeps a tile error quiet only if `err.status === 404`.
- geomatico's in-browser COG reader assumes EPSG:3857 and writes nodata as opaque 0 m unless the app's colour function (registered per URL) says otherwise.
- The `<Map maxBounds>` prop is a second path into MapLibre's constrain besides `applyBoundedView`; sanitise at the state setter.
- Library entries are copies in localStorage: ship fixes with the id unchanged and let the on-load refresh (`TerrainViewer.tsx`, "Library-managed sources") pick them up.
- Pushing to main deploys production; the user asks for pushes explicitly (see the user-level memory).
