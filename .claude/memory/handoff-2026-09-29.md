  `docs/src/data/research-references.json`, 120 entries, each DOI-checked):
  grouped by field (landscape archaeology first, earth surface processes,
  historical imagery, methods, elevation data); study-area links open the app
  on Mapterhorn unless a finer library dataset exists in that country (6 do);
  [cites RVT]/[cites GLO-30] from OpenAlex; "See the elevation change" links.

  per section under MDX headings (TOC), one shared store for all filter bars,
  header filters (year range, link present/absent, cites), sticky header while
  the table fits the page, CSV, URL state (`columns`, unknown keys dropped).
- **Dataset DOIs** `docs/src/data/dataset-dois.json`: producer DOI, else
  OpenTopography mirror DOI, else producer programme page; shown in the
  National Datasets tables and "Citing the data".
- **National Datasets page**: columns Dataset, View (Open Solo / vs Mapterhorn
  side-by-side), Coverage, API resolution, Mapterhorn, Bulk download, Served
  as, Endpoint; group headings in MDX with plain lucide chevrons (`Trend`);
  regional table compared to Mapterhorn; surface models (DSM/DOM/nDSM) in
  their own section; "Global and non-DTM" and "Procedures" groups.
- **Six event change pairs** in `lib/custom-sources.json` (Kaikoura, Kilauea,
  Fagradalsfjall, Columbia Glacier, Chamoli, Ridgecrest), each decoded in-app.
- **nDSM spikes fixed**: see [[wms-nodata-two-paths]] (nodata markers on the
  client `float32dem-bbox://` path, hole mask alpha 254, no dilated band).
- **3D terrain before all tiles load**: view setup runs on `style.load` via
  `readyHandlers` (TerrainViewer.tsx); MapLibre `load` waits for every tile.
- **Wayback**: picks only releases with a known capture date; held release is
  a placeholder while a new place resolves; no metadata timeout (user asked).
- **IGN LiDAR HD WMS in 1024 px tiles** (`tileSize` on wms-raw, GetMap 1026);
  demdiff URL carries operand start depth `256~d~d`.
- Timeline: compare-dates button right of the title (historical on every view,
  pills synced, toggles side-by-side / overlay); endless middle-drag via
  pointer lock. Sidebar docs button (`TooltipIconButton href`, middle-click).
  `?place=` fills the geocoder placeholder expanded. GE date past the newest
  capture snaps to it. Docs next.config `allowedDevOrigins` includes LANs.
